Grade a diff

Paste a unified diff, or upload a diff file — the file wins when both are given. Describe what the diff is supposed to do: the model was trained on full task text, and a bare title grades worse. Test output is optional; it reaches the model as the grading state's notes. Grading runs the model on this machine and can take a few minutes the first time (the model loads, then grades).
