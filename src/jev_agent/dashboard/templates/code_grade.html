Grade a diff

Paste a unified diff, or upload a diff file — the file wins when both are given. Describe what the diff is supposed to do: the model was trained on full task text, and a bare title grades worse. Test output is optional; it reaches the model as the grading state's notes. Grading runs in the background and can take a few minutes — the model loads first (about a minute), then grades (1–3 minutes for a small diff, up to about 10 for a large one). The result waits on the status page; you can leave this page, close the tab, or come back later, and the grade is still there. One grade runs at a time.
