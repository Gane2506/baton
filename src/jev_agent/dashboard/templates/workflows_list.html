Workflow profiles

A workflow profile is a stage list plus parameters: which stages a run goes through, in canonical order, and how each step behaves. Profiles never reorder stages — the order is fixed by the stages' data dependencies — and the safety floor in the design always applies. The default flow (no profile) is unchanged.
