What Figma allows — and what it doesn't

Writing needs a Full seat (a Dev seat is read-only) and edit access to the file. The write tools are beta — free now, planned usage-based paid later — and rate-limited: about 20 MCP tool calls a month on Starter, about 200 a day for a Full seat on Professional or above. Work on a duplicate or draft before touching a production file, and keep a backup: agent writes are beta. If the official MCP server's gates bite, the community Figwright pattern (MCP server + local plugin over WebSocket, works on the free tier) is the fallback — the same generated script runs through it. A dedicated Baton Figma plugin is only needed if neither path is available: it would run this same script in the open file.
