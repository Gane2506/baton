MCP servers (CLI only)

jev mcp servers and jev mcp runs serve MCP over stdio to a local MCP client. A browser page cannot hold the other end of that pipe, so these stay in the terminal:

jev mcp servers
Serves list_servers, run_command, read_file (and write_file at medium access) over stdio. Every call is checked against the access policy and audited.
jev mcp runs
Serves the pipeline tools (run_list, run_status, run_start, quality_show, chat_send) over stdio; every call is audit-logged.
